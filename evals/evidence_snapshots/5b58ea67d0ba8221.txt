TITLE: Access instance metadata for an EC2 instance - Amazon Elastic Compute Cloud

To retrieve instance metadata using an IPv6 address, ensure that you enable and use the IPv6 address of the IMDS [fd00:ec2::254] instead of the IPv4 address 169.254.169.254.
