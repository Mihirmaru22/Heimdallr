## 3. Runtime Evaluation Boundary Isolation

### 3.1 GroundTruthAccessGuard Verification

The `GroundTruthAccessGuard` proxy pattern wraps all runtime objects passed into the `InvestigationEngine` and `EvalV2Runner`. Any attempt by production code or specialists to read attributes matching `expected_*`, `ground_truth`, or `grader` triggers an immediate `GroundTruthLeakageViolation` exception.

- **Probes Executed**: 140 Capability Match V2 tasks, 129 Eval V2 tasks, 25 Investigation V1 tasks.
- **Guard Interceptions / Violations**: 0
- **Leakage Rate**: **0.0%**

### 3.2 Epistemic State Isolation

Candidate observations generated by `OpenSanctionsAdapter` enter the investigation state under strict quarantine:
1. `is_authoritative = False`
2. `epistemic_status = "OBSERVATION"`
3. The candidate output is stored in unprivileged raw observation buffers and cannot mutate verified entities or claims until processed and corroborated by Heimdallr's verification pipeline.
