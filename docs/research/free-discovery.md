# WebData AI: free company and website discovery options (checked 2026-10-19)

**How this was checked.** Every row was checked on 2026-10-19 through WebFetch on the provider's own page, unless the row says otherwise. Library versions and licences come from the PyPI JSON API. Direct curl to provider sites and the GitHub API were blocked in this sandbox. Labels used below:
- **[3P]**: the fact comes from a third-party page, used only because no first-party page could be read.
- **unverified**: the fact could not be confirmed from any page I opened.
- **"Not stated"**: the provider's page I opened does not say.

Free can mean three different things, so the Free? column says which:
- **SW**: free software that you run yourself.
- **Data**: a free dataset or download.
- **API-free**: a hosted API that costs $0 within a quota.
- **Credits**: free credits at signup or each month, on an otherwise paid API.

## 2. Recommended free discovery stack for the MVP (ranked)

1. **Wikidata SPARQL**, filtered by industry (P452), country (P17) and HQ (P159). It returns company, official website (P856) and HQ in one query. It is CC0 and needs no key, so it should be the first source for "N companies in sector X, region Y". Weak for SMEs.
2. **National registry APIs and bulk files** give complete SME lists filtered by industry code: France (recherche-entreprises, 7 req/s, no key), UK Companies House (600 per 5 min, free key), Norway Brønnøysund (NLOD), Finland PRH (bulk JSON), Estonia (CC BY 4.0 bulk). They are authoritative for name, HQ and NACE/SIC code, but **mostly have no website**, so they must be paired with steps 3 and 4.
3. **Self-hosted SearXNG with JSON enabled** as the default "company name to official website" resolver and general query engine. $0 and local. Accept that throttling and engine-ToS risk exist: keep volume low, cache aggressively, and prefer the less hostile engines (Brave, Mojeek, Wikipedia, Wikidata).
4. **Rotate the free API credits as an optional fallback**: Tavily 1,000/month, Firecrawl 1,000 credits/month, Exa $10/month, Brave $5/month, SerpApi 250/month, Jina 5 RPM with no key. Together these give roughly 3–5k reliable lookups a month at $0 through official APIs. Use them only when SearXNG fails.
5. **GLEIF API (CC0)** to deduplicate entities and confirm HQ country and legal name. Use **SEC EDGAR** for US listed companies.
6. **Site expansion once a domain is known**:
   - ultimate-sitemap-parser (GPL; or trafilatura's sitemap module, Apache) plus Protego for robots.txt.
   - **Common Crawl CDX via cdx_toolkit** as a fallback URL lister when a site has no sitemap.
   - Pick pages by URL pattern (/pricing, /products, /contact, /about).
7. **Extraction**: trafilatura for text, extruct for JSON-LD `Organization` (logo, address, sameAs, email), courlan and tldextract for URL hygiene. Crawl with Scrapy or Crawlee. Use Crawl4AI only when JS rendering is needed.
8. **Ranking and spam filtering**: the Tranco list (daily, top 1M) and the **Common Crawl domain ranks file** (local, 2.2 GiB) to score domain authority and drop parked or spam domains. Use Open PageRank (30k domains/month) if you don't want to download the file.
9. **Optional niche enrichers**: the GitHub org `blog` field (tech firms, 5,000/h with a token), the HN API, OSM Overpass `website=` tags (low volume only), crt.sh for subdomains.

## 3. Options ruled out

- **Google Custom Search JSON API**: closed to new customers; migration must be completed by Jan 1, 2027.
- **Bing Search APIs**: retirement announced for Aug 11, 2025. The replacement is paid Azure grounding.
- **Stract**: repo archived Apr 2, 2026.
- **Crunchbase API**: free Basic API deprecated in 2023 [3P]. Paid only.
- **OpenCorporates API**: paid (from £2,250/yr). Free only for public-benefit applicants.
- **KVK (NL) API**: €6 per month, so not $0. Its CC-BY open dataset is too thin to replace it.
- **Mojeek API**: needs a bank card; pay-as-you-go after a small credit. Fine as a paid add-on, not part of a $0 stack.
- **Marginalia API**: free keys are CC-BY-NC-SA (non-commercial), and the index is skewed to small personal sites.
- **Product Hunt API**: non-commercial by default; maker data redacted.
- **Clearbit Logo API**: shut down Dec 8, 2025. Autocomplete status is unverified and undocumented, so don't build on it.
- **DuckDuckGo direct scraping / `ddgs` as a primary source**: no official API, the library says "educational purposes only", and it is fragile. Use only as a last-resort fallback.
- **YaCy as a discovery source**: it only knows what you crawl. Useful as a local crawler and index at most.
- **CrUX**: needs a GCP billing account and runs in the cloud, not locally. Tranco already includes CrUX.
- **EU BRIS**: no API; manual search only.
- **DBpedia**: duplicates Wikidata with more lag; partial results on timeout.
- **Germany OffeneRegister / Handelsregister bulk, India MCA, Denmark CVR**: no current free, first-party bulk API could be verified. Revisit later if those countries matter.
